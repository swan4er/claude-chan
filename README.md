# claude-chan

Claude-чан — маленькая рыжая аниме-помощница, которая живёт над строкой ввода Claude Code. Она
реагирует на работу Claude (задумалась, обрадовалась, встревожилась, задремала на долгом ходе) и
разговаривает в бабле: вы пишете ей, отвечает модель, выражение лица подбирается по настроению ответа.

Это мод Claude Code на **function hooks** (ранний доступ): TypeScript, который выполняется внутри
процесса Claude Code. API может меняться между релизами.

## Где работает

Рассчитана на обычные терминалы: Windows Terminal, Terminal.app, встроенные терминалы VS Code и
Zed, tmux. Для этого:

- портрет нарисован **цветными полублоками** (`▀▄█`), а не настоящей картинкой: элемент `Image`
  движка работает только в kitty и Ghostty;
- **палитра подобрана под 256 цветов.** Terminal.app и tmux 24-битного цвета не дают, и Claude Code
  сам огрубляет цвета; оттенки выбраны так, чтобы после огрубления лицо выглядело так же
  (`npm run preview` рисует оба варианта рядом, тест это проверяет);
- **мышь не нужна.** Говорить с ней можно командой, а поле ввода получает фокус с клавиатуры;
- в низком или узком окне (меньше 11 строк над строкой ввода или 56 колонок) вместо портрета —
  одна строка со смайликом.

Проверено вживую в tmux (палитра 256) на Linux. В остальных терминалах не запускалась.

## Установка

1. В `~/.claude/settings.json` добавить (или слить с существующим ключом `env`):

   ```json
   { "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
   ```

   Это включает модули хуков у всех установленных плагинов. Нужен Claude Code 2.1.269 или новее.

2. Поставить плагин из папки — она сама себе marketplace:

   ```sh
   claude plugin marketplace add /путь/к/claude-chan
   claude plugin install claude-chan@claude-chan
   ```

3. Перезапустить `claude`, выполнить `/chan`.

Без установки, на один запуск: `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir /путь/к/claude-chan`.

Обновление: поднять `version` в `.claude-plugin/plugin.json` → `claude plugin marketplace update claude-chan`
→ `claude plugin update claude-chan@claude-chan` → перезапуск. Без смены версии обновление не придёт.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `/chan` | показать или скрыть; состояние запоминается между сессиями |
| `/chan <текст>` | сказать ей что-нибудь — ответ появится в бабле |
| `/chan off` | скрыть |
| `/chan chatty on` / `off` | болтливый режим: конец хода Claude и упавшие команды комментирует модель |
| `/chan reset` | забыть разговор |

Поле ввода под портретом: `ctrl+x tab` переводит на него фокус, Enter отправляет, Esc возвращает
клавиатуру строке ввода.

## Сколько это стоит

- Реакции на события по умолчанию — **готовые фразы, бесплатно.**
- Каждая ваша реплика — один запрос к модели `haiku` за счёт вашей подписки: системный промпт,
  до восьми последних реплик разговора, ответ до 220 токенов. Отклик около секунды.
- В болтливом режиме запрос уходит ещё и на каждое завершение хода и на упавшую команду
  (не чаще раза в 20 секунд). Поэтому он выключен, пока вы его не включите.
- Отдельный процесс Claude не запускается: мод зовёт модель через `$.model.complete`.

Claude-чан не выполняет команд и не читает файлы: она знает только то, что ей написали, а в
болтливом режиме — ещё конец последнего ответа Claude (до 400 символов). С просьбами про код она
отправляет к большому Claude в строке ввода.

## Устройство

- `hooks/chan/portrait.ts` — пиксель-арт 16×18: базовое лицо и «наклейки» выражений (глаза, брови,
  рот), моргание, речь; перевод в отрезки полублоков с прозрачным фоном; палитра и расчёт того, как
  её покажет терминал на 256 цветов. Править картинку = править карту символов.
- `hooks/chan/persona.ts` — системный промпт, теги настроения (`[радость]`, `[тревога]`…), разбор и
  очистка ответа (эмодзи ломают рамку бабла), короткая память, готовые реплики на события.
- `hooks/chan/bubble.ts` — перенос по словам, «печать» по буквам, моргание.
- `hooks/register.tsx` — хуки: команда, запрос к модели, реакции на `turn.start`, `turn.complete`,
  `tool.call`, отрисовка в `AbovePrompt`. Поверхности `Client` нет: быстрый цикл не нужен, поэтому
  мод не зависит от мыши и полноэкранного режима.

Общая инструкция по function hooks для агентов — `docs/agent-notes.md`.

## Разработка

```sh
npm test             # портрет, палитра, бабл, характер: node --test (node 24+)
npm run test:hooks   # хуки в окружении движка с подменённой моделью: claude plugin test
npm run typecheck    # tsc; типы API кладёт /plugin-types в .claude/types
npm run preview      # лист выражений в PNG: сверху полный цвет, снизу палитра 256
node tools/ansi2png.ts снимок.ansi кадр.png   # снимок терминала (tmux capture-pane -e -p) → PNG
```

## Чего пока нет

Голоса (`$.audio.speak` есть, но на удалённом сервере звука нет), комментариев с полным знанием
переписки (`$.model.fork`), поз в полный рост, настройки характера и модели через конфигурацию плагина.
