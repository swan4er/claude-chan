# claude-chan

Мод Claude Code на function hooks: аниме-помощница Claude-чан в полосе над строкой ввода.

Перед любой правкой прочитай `docs/agent-notes.md` — инструкцию по function hooks с измеренными
ограничениями среды и типовыми ошибками. Устройство мода — в `README.md`. Требование владельца:
работать в обычных терминалах (Windows Terminal, Terminal.app, VS Code, Zed, tmux) — без элемента
`Image`, без мыши, палитра под 256 цветов.
